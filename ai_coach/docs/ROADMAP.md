## 技術債務

### 📋 待重構

| 項目 | 優先級 | 說明 |
|------|--------|------|
| `train.py` 模塊化 | 中 | 拆分訓練邏輯為獨立模塊 |
| 配置硬編碼 | 高 | 移至 config.py |
| 錯誤處理 | 高 | 更詳細的異常類型 |
| 字體路徑 | 中 | 改進跨平台路徑邏輯 |
| 文檔字符串 | 中 | 補充更多示例 |

### 🐛 已知問題

1. **字體渲染**
   - Windows 上某些字體不可用
   - 需要改進字體檢測邏輯
   - 優先級: 低

2. **線程同步**
   - 高並發時偶爾出現競態條件
   - 需要添加更多單元測試
   - 優先級: 中

3. **API 超時**
   - vLLM 服務器無響應時缺少重試邏輯
   - 優先級: 中

4. **內存洩漏**
   - 長時間運行時內存增長
   - 需要性能分析
   - 優先級: 低
