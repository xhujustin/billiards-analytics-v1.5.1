# Tools

Standalone helper scripts for development, experimentation, and data preparation.

## Files

- `dataset_builder.py`: prepares or reshapes training data
- `performance_optimizer.py`: profiling and optimization helpers
- `personalized_advisor.py`: advisor-oriented orchestration utilities
- `websocket_coach.py`: websocket serving and integration helpers

## Guidance

- Keep reusable library code in `src/ai_coach/`.
- Keep one-off workflows and operational scripts in `tools/`.
