# 遊玩模式指南

## 05/14: '新增遊玩模式選擇 UI'

### 範例

遊玩模式頁提供四種入口，讓使用者從即時分析快速進入不同遊戲流程：

```text
Dashboard -> Game -> GamePage mode=setup
```

主要卡片：

- 任務挑戰
- 好友對戰
- 9 號球
- 限時挑戰

### 規範用法

- 首頁狀態維持 `currentPage='game'`，由 `GamePage` 控制內部模式。
- 任務挑戰、9 號球與限時挑戰目前先保留 UI 與 mock data。
- 好友對戰會進入完整設定流程，確認後沿用既有 `/api/game/start`。
- 遊戲模式不再依賴 AI Coach 側欄；AI Coach 只保留在即時影像與訓練頁。

### 輸出格式

遊戲紀錄卡片可輸出：

```json
{
  "時間": "2024/06/05 20:15",
  "遊玩模式": "9 號球",
  "任務名稱": "9 球清台挑戰",
  "結果": "完成",
  "分數": "150 分",
  "耗時": "03:45"
}
```

結果狀態規範：

- `完成`：任務或對戰正常完成。
- `失敗`：挑戰未達目標。
- `進行中`：尚未結束的遊戲。

## 05/15: '新增好友對戰建立 UI'

### 範例

遊玩模式頁點擊 `好友對戰` 卡片後，進入好友對戰設定流程。

### 設定流程

好友對戰設定分為：

- 玩家邀請
- 遊戲類型
- 對戰局數
- 出桿時間限制
- 自動判定與紀錄
- 開始前檢查
- 開始對戰

### Mock 行為

玩家 1 預設顯示目前帳號 `@123` 或登入使用者名稱。玩家 2 初始為等待加入狀態。

邀請按鈕：

```json
{
  "分享 QR Code": "讓玩家 2 模擬加入",
  "輸入好友代碼": "讓玩家 2 模擬加入"
}
```

### 遊戲設定

遊戲類型第一版只開放 `9 球`，`8 球`、`10 球` 與 `自訂規則` 顯示為 disabled。

局數選項：

```json
["3 局", "5 局", "7 局", "自訂局數"]
```

出桿時間限制：

```json
["不限時", "每桿 30 秒", "每桿 45 秒", "每桿 60 秒", "自訂"]
```

自動判定與紀錄：

```json
[
  "自動進球計分",
  "犯規偵測",
  "合法擊球提示",
  "自動儲存對戰紀錄",
  "產生賽後分析報告"
]
```

### 輸出格式

開始對戰時應整理設定物件：

```json
{
  "players": ["玩家1", "現場好友"],
  "gameType": "nine_ball",
  "targetRounds": 5,
  "shotTimeLimit": 30,
  "options": {
    "auto_pot_detection": true,
    "foul_detection": true,
    "auto_scoring": true,
    "target_ar_hint_enabled": true,
    "saveBattleRecord": true,
    "generatePostMatchReport": true
  }
}
```
